## Working capabilities

- Additive authenticated Observatory product wrapper and typed frontend client. Original product API V1_3 remains untouched.
- Bounded synthetic signal-window reconstruction through delegated *canonical* gap, resampler and causal filter operators, followed by the canonical per-window normalization. No frontend inference or independent JavaScript signal processing. Selected traces are classified `DETERMINISTIC_LOCAL_RECONSTRUCTION` and are not called historical captured traces.
- Explicitly armed, owner-scoped live capture for one new monitoring-session window. Instance-local delegating observers capture actual source, gap, resampler and filter values before the runtime emits the selected quality/window result. The response is classified `CAPTURED_LIVE_PREPROCESSING`; memory-only storage is capped at two captures, one hour, and 750 kB per response. The emitted filtered window is normalized separately by the existing canonical routine for inspection; this is **not** a gateway-side normalization/logit hook. Recorded MODEL_V2_FINAL inference is attached from persisted evidence by source timestamp. No extra inference is run by opening the capture.
- Owner-scoped persisted-session attachment of recorded MODEL_V2_FINAL inference metadata. Raw `inference_events.context_json` is never read into the response; context availability comes from projected public `context_snapshots`.
- Signal view with synchronized physical-time axes, null gaps, source/window/quality/context/normalization summaries, scenario selection and window scrubber. Each plotted stage has a keyboard-accessible rendered-point cursor showing its actual value, source timestamp, and source index when present. Chart points are decimated; processing uses the complete canonical array. Full 2,500-point export/pan/zoom is not yet implemented.
- Read-only, hash-checked V2-FL-005 synthetic cohort roster; eight participants and distinct fault/window/label profiles. It is engineering evidence, not AAMI-SVF efficacy.
- Any of the eight frozen synthetic FL clients can now be opened in an authenticated client-window inspector. Its observed source is generated by the actual FL cohort source, fed through the same delegated canonical stream operators, and its eligible window receives a label from the existing client-local `WEARABLE_SIM_EVENT_WINDOW_V1` adapter. Excluded windows receive no fabricated label. SITE_07's long-gap window 48 is visibly `UNUSABLE`/excluded; SITE_00's eligible window 18 has the scheduled-event engineering label 1. Opening this view performs no local optimization.
- Owner-scoped run-contribution view and expandable eight-client/all-round matrix. Intermediate checkpoints preserve coordinator-accepted per-client digests for rounds 1 and 2. The final round has no directly persisted coordinator map; a completed run may nevertheless recover its per-client identities and weights through the ordered server journal, exact training-record digest/example reconciliation, SQLite round count, final candidate digest, and the persisted five-check governance decision (which validated the actual in-memory coordinator map). This is explicitly labelled `GOVERNANCE_ATTESTED_SERVER_JOURNAL`, distinct from `DIRECT_COORDINATOR_MAP`; any missing or contradictory part fails closed to `NOT_RECORDED`. SUBMITTED status alone never proves acceptance. Batch loss, update norm and payload size remain not durably recorded for this run.
- New completed Observatory-hosted LIVE_RUNs also write a separate post-run, hashed acceptance sidecar from the actual in-memory coordinator map for **every** round, including the final round. It is `DIRECT_OBSERVED_COORDINATOR_MAP` evidence, not inferred from SUBMITTED. The sidecar is outside frozen FL artifacts and cannot change a run outcome; absent sidecars retain the historical evidence basis above. Batch loss, update norm and payload size remain not durably recorded.
- Sixteen-step guided tour that links to functioning signal/federation views and existing frozen ML/FL research pages, clearly marking missing capabilities rather than fabricating data.
